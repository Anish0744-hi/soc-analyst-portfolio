# Security Policy

## Scope

This repository contains educational materials, cybersecurity labs, and SOC Analyst learning projects.

## Supported Versions

This is a learning portfolio. Security fixes will be considered for the current version of the projects maintained in this repository.

| Version | Supported |
|---------|-----------|
| Current | Yes |
| Older versions | No guarantee |

## Reporting a Vulnerability

If you discover a security vulnerability in one of my projects, please report it privately through GitHub's private vulnerability reporting feature, if available.

Please do not publicly disclose sensitive vulnerability details before the issue has been reviewed.

## Responsible Use

All cybersecurity tools, scripts, and demonstrations in this repository are intended for authorized testing, education, and defensive security research only.

Do not use these materials to access systems without permission.
